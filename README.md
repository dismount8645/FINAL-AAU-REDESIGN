# AAU Redesign Web Portal

A modern, responsive web portal for Aalborg University students, built with React, TypeScript, and Vite.

## Getting Started

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Start development server:**
    ```bash
    npm run dev
    ```

3.  **Run tests:**
    ```bash
    npm test
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```

## Project Structure

- `src/api`: API service and mock data handling.
- `src/components`: Reusable UI and layout components.
- `src/features`: Larger feature-specific modules (e.g., Calendar).
- `src/hooks`: Custom React hooks.
- `src/store`: State management (Zustand).
- `src/styles`: Global styles and Tailwind configuration.
- `src/test`: Testing utilities and configuration.
- `src/widgets`: Dashboard widget implementations.

## Technologies

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Zustand** (State management)
- **Vitest** (Testing)
- **Lucide React** (Icons)
